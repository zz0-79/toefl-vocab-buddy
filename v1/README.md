# 词途 · 第一版（归档）

本文件夹保存 **改版前** 的完整网页代码，便于与当前第二版对比或演示演进过程。

## 与第二版的区别

| 项目 | 第一版（本目录） | 第二版（项目根目录） |
|------|------------------|----------------------|
| 界面 | 功能模块较多，一屏信息较满 | 突出「输入单词」，次要功能收到底部 Tab |
| 查词 |  mainly 随机推荐 / 历史浏览 | **顶部输入框查询** + 最近查询 |
| 在线地址 | `/v1/` 子路径 | 网站首页 `/` |

## 本地预览第一版

```bash
cd v1
python3 -m http.server 8081
```

浏览器打开：http://localhost:8081

## 文件说明

- `index.html` — 页面结构  
- `styles.css` — 样式  
- `app.js` — 逻辑（艾宾浩斯、游戏化、API、LocalStorage）

> 第一版与第二版若在同一域名下打开，浏览器 LocalStorage 可能共用；分开测试时可使用不同浏览器或无痕模式。
