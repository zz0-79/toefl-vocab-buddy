# 词途 · TOEFL 词汇学习伙伴（第二版 · 当前）

为「渴望进步的小李」设计的交互式词汇学习网页，解决背词遗忘、缺乏正向反馈、拖延等问题。

详见 [VERSION.md](VERSION.md) · 第一版代码在 [`v1/`](v1/) 文件夹。

## 功能亮点

### 科学复习（艾宾浩斯）
- 掌握新词后自动排期：**1 → 3 → 7 → 14 → 30 天**复习
- **今日待复习**列表，第 2 天复习昨天学的词
- **每 7 天周测**（5 题选择题）

### 游戏化
- **今日打卡** + 连续天数 🔥（类多邻国）
- **XP / 等级 / 徽章**
- **词汇闯关**小游戏

### 心理正向循环
- 「用对方法 → 背得住 → 有成就感 → 更愿意背」可视化
- 对抗「死记硬背→记不住→不想背」

### 技术与基础
- **词典 / 微习惯 / 治愈图** 三个 API
- **LocalStorage v2** 持久记忆（含复习计划、XP、打卡）
- 每日新词目标 **1～30**（默认 3，熟练后可调高）

## 交互元素（≥3）

| 交互 | 说明 |
|------|------|
| 心情打卡 | 选择今日心情，获得个性化鼓励 |
| 标记已掌握 | 记录词汇并计入今日目标 |
| 收藏单词 | 加入复习收藏夹 |
| 播放发音 | 调用 API 返回的音频 URL |
| 换一个词 / 上一条下一条 | 浏览学习历史 |
| 每日目标滑块 | 自定义并保存每日词数 |
| 微习惯 / 治愈图按钮 | 拉取外部 API 数据 |
| 拖拽排序 | 在已掌握/收藏列表中调整复习顺序 |
| 清空记录 | 一键重置本地数据 |

## 本地预览

```bash
cd toefl-vocab-buddy
python3 -m http.server 8080
```

浏览器打开：http://localhost:8080

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（例如 `toefl-vocab-buddy`）
2. 将本文件夹内 `index.html`、`styles.css`、`app.js` 推送到仓库
3. 进入仓库 **Settings → Pages**
4. **Source** 选择 `Deploy from a branch`
5. **Branch** 选 `main`，文件夹选 `/ (root)`
6. 保存后访问：`https://<你的用户名>.github.io/toefl-vocab-buddy/`

> 若使用 `docs/` 目录部署，把三个文件放入 `docs/` 并在 Pages 设置中选择 `/docs`。
