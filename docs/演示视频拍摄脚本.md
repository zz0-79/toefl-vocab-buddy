## 演示艾宾浩斯的小技巧

若录制当天没有「到期复习」，可以：

1. 掌握 1 个词后，在浏览器 F12 → Application → LocalStorage → 把该词 `nextReview` 改成今天日期；或  
2. 旁白说明：「系统会在第 2 天自动提醒复习」，同时展示「复习日程」标签页中的下次日期。
